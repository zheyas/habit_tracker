# 🧠 Трекер полезных привычек

Backend-проект для отслеживания и формирования полезных привычек, разработан в рамках курсового проекта SkyPro.

---

## 📦 Стек технологий

- Python 3.10+
- Django 4.x
- Django REST Framework
- PostgreSQL
- Celery + Redis
- Telegram Bot API
- drf-yasg (Swagger UI)
- JWT (SimpleJWT)
- .env (python-dotenv)
